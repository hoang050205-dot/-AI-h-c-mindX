03. So Sánh Các Phương Án Kỹ Thuật (Trade-off Matrix)

Approach 1: Lean / Direct
Khuyên Dùng
Script Python thuần (openpyxl) kết hợp tiền xử lý dữ liệu và tạo trực tiếp workbook Excel đa sheet.
Ưu Điểm
  • Triển khai cực nhanh trong 1-2 giờ
  • Hoàn toàn kiểm soát mã nguồn, không tốn phí API
  • Dễ debug và bảo trì trực tiếp trên máy
Nhược Điểm
  • Không tự động lấy dữ liệu thời gian thực nếu dữ liệu mạng thay đổi
Giả định chịu lực cốt lõi:Dữ liệu mẫu 22 quán đã được thu thập và thẩm định cấu trúc trước khi sinh file.
Điểm gãy đầu tiên (First failure):Nếu cấu trúc nguồn thay đổi đột ngột hoặc schema bị thiếu trường bắt buộc.
Approach 2: Workflow / Agentic
Khả Thi Cao
Pipeline tác tử 2 tầng: Agent 1 làm sạch & xác thực schema -> Agent 2 phân tích kinh doanh và tạo dashboard.
Ưu Điểm
  • Có thể xử lý thêm nhiều nguồn dữ liệu mới
  • Có trạm kiểm soát (Human Checkpoint) trước khi xuất file
Nhược Điểm
  • Phức tạp hơn, cần kiểm soát token và context handoff giữa các agents
Giả định chịu lực cốt lõi:Khuôn mẫu dữ liệu trung gian giữa 2 Agent được giữ nhất quán tuyệt đối.
Điểm gãy đầu tiên (First failure):Agent 1 xuất sai định dạng schema khiến Agent 2 không thể sinh công thức Excel.
Approach 3: Scalable / Advanced
Quá Tải (Overkill)
Xây dựng microservice crawl tự động từ Google Places API, lưu vào PostgreSQL và vẽ dashboard qua Web App.
Ưu Điểm
  • Khả năng mở rộng toàn quốc cho hàng nghìn quán
  • Cập nhật dữ liệu real-time
Nhược Điểm
  • Thời gian dựng 1-2 tuần, tốn chi phí API key và hạ tầng hosting
  • Vi phạm nguyên tắc YAGNI/Lean cho quy mô bài tập
Giả định chịu lực cốt lõi:Cần nguồn ngân sách duy trì API và có đội ngũ vận hành hạ tầng backend.
Điểm gãy đầu tiên (First failure):Hết hạn mức chi phí Google API hoặc tài khoản thẻ ngân hàng bị chặn.
